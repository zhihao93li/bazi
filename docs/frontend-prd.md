# 八字命理 - 前端产品需求文档 (PRD)

## 1. 产品概述

八字命理是一个基于传统命理学与现代 AI 技术的命理分析平台，为用户提供精准的八字排盘和深度命理解读服务。

### 1.1 技术选型

- **框架**: React（不使用 Next.js）
- **路由**: React Router
- **状态管理**: React Hooks + Context
- **样式**: Tailwind CSS
- **动画**: Framer Motion

---

## 2. 页面结构总览

| 页面路径 | 页面名称 | 认证要求 | 核心职责 |
|---------|---------|---------|---------|
| `/` | 首页 | 否 | 产品介绍与入口 |
| `/login` | 登录/注册 | 否 | 用户认证 |
| `/bazi/input` | 八字输入 | 否 | 收集出生信息 |
| `/bazi` | 排盘结果 | 否 (AI分析需登录) | 展示命盘 + AI报告 + 人物切换 |
| `/history` | 历史记录 | 是 | 报告列表管理（查看/删除） |
| `/points` | 积分中心 | 是 | 积分充值与明细 |
| `/profile` | 用户中心 | 是 | 账户管理 |
| `/subjects` | 测算对象 | 是 | 测算对象增删改 |

### 2.1 页面职责说明

| 页面 | 职责 | 说明 |
|-----|------|------|
| `/bazi` 排盘结果页 | 展示 + 生成 | 核心页面，展示命盘和AI报告，支持人物切换 |
| `/history` 历史记录页 | 管理 | 报告列表管理，点击跳转到 `/bazi?reportId=xxx` 查看详情 |
| `/subjects` 测算对象页 | 管理 | 对象增删改，点击「测算」跳转到 `/bazi?subjectId=xxx` |

## 6. 八字输入页 (`/bazi/input`)

### 6.1 功能

- 收集用户出生信息
- 支持公历/农历输入
- 支持选择出生地点（用于真太阳时校正）
- 支持预填已保存的测算对象信息

### 6.2 展示信息

| 区域 | 内容 |
|-----|------|
| 页面标题 | "八字排盘 - 输入出生信息，探寻生命密码" |
| 表单标题 | "输入您的出生信息" |

### 6.3 输入字段

| 字段 | 类型 | 选项范围 | 必填 |
|-----|------|---------|------|
| 性别 | 开关选择 | 男/女 | 是 |
| 历法 | 开关选择 | 公历(阳历)/农历(阴历) | 是 |
| 年份 | 下拉选择 | 1920-当前年 (倒序) | 是 |
| 月份 | 下拉选择 | 1-12月 | 是 |
| 日期 | 下拉选择 | 1-31日 | 是 |
| 时辰 | 下拉选择 | 0-23时 | 是 |
| 分钟 | 下拉选择 | 0-59分 | 是 |
| 出生地点 | 省市级联选择 | 全国省市 | 是 |
| 闰月 | 复选框 | 是/否 | 否 (仅农历时显示) |

### 6.4 交互逻辑

| 操作 | 行为 |
|-----|------|
| 切换"农历" | 显示"是否为闰月"选项 |
| 点击"排布命盘" | 验证表单 → 调用排盘API → 成功后跳转 `/bazi` |
| 排盘失败 | 显示错误提示，保留用户输入 |

### 6.5 入口场景

| 入口 | URL | 行为 |
|-----|-----|------|
| 首页「立即排盘」| `/bazi/input` | 空表单 |
| 导航栏「八字排盘」| `/bazi/input` | 空表单（或恢复上次输入） |
| 结果页「重新排盘」| `/bazi/input` | 预填当前数据 |
| 带 subjectId | `/bazi/input?subjectId=xxx` | 预填该对象的出生信息 |

| 操作 | 行为 |
|-----|------|
| 点击"开始AI分析" (未登录) | 弹窗提示 → 确认后跳转 `/login?callbackUrl=/bazi&pending=true` |
| 点击"开始AI分析" (积分不足) | 弹窗提示 → 确认后跳转 `/points` |
| 点击"开始AI分析" (正常) | 扣除积分，生成分析报告 |
| 点击"重新排盘" | 跳转 `/bazi/input`，预填当前数据 |
| 切换测算对象 | 加载该对象的命盘/报告数据 |
| 直接访问无数据 | 自动跳转 `/bazi/input` |

### 7.4 入口场景与状态处理

| 入口 | URL | 页面行为 |
|-----|-----|---------|
| 输入页排盘成功 | `/bazi` | 显示新排盘的命盘 |
| 测算对象「测算」| `/bazi?subjectId=xxx` | 加载该对象最近的命盘/报告 |
| 历史记录「查看」| `/bazi?reportId=xxx` | 直接显示该报告详情 |
| 登录后返回 | `/bazi?pending=true` | 从 sessionStorage 恢复之前的状态 |
| 充值后返回 | `/bazi?subjectId=xxx` | 恢复之前的对象数据 |

### 7.5 切换对象时的状态处理

| 该对象的数据状态 | 页面显示 |
|----------------|---------|
| 无任何数据 | 跳转 `/bazi/input?subjectId=xxx`，预填出生信息 |
| 有命盘，无AI报告 | 显示命盘，AI区域显示「开始分析」按钮 |
| 有命盘 + AI报告 | 显示完整内容（最近一次报告） |

## 12. 页面跳转流程

```
首页 (/)
  └─→ 立即排盘 → /bazi/input (空表单)
                    └─→ 排盘成功 → /bazi (显示命盘)
                                    ├─→ AI分析(未登录) → /login → 返回 /bazi?pending=true
                                    ├─→ AI分析(积分不足) → /points → 返回 /bazi
                                    ├─→ 切换人物 → /bazi?subjectId=xxx (加载该人数据)
                                    └─→ 重新排盘 → /bazi/input (预填数据)

历史记录 (/history) ← 需登录
  └─→ 点击查看 → /bazi?reportId=xxx (直接显示报告)

测算对象 (/subjects) ← 需登录
  └─→ 点击测算 → /bazi?subjectId=xxx (加载该人数据)

登录页 (/login)
  └─→ 登录成功 → callbackUrl 或 /bazi

用户中心 (/profile) ← 需登录
  └─→ 退出登录 → /
```

## 13. 未登录用户体验

| 阶段 | 行为 |
|-----|------|
| 输入出生信息 | ✅ 正常使用 |
| 查看命盘结果 | ✅ 正常查看 |
| 点击AI分析 | 弹窗提示「需要登录」→ 跳转登录页 |
| 登录后返回 | 自动恢复之前的命盘数据，继续分析流程 |

### 数据保持方案

登录前将数据暂存到 `sessionStorage`：

```javascript
// 跳转登录前
sessionStorage.setItem('pendingBazi', JSON.stringify({
  formData: {...},   // 表单输入
  baziResult: {...}  // 排盘结果
}));

// 登录回调 /bazi?pending=true 时
// 从 sessionStorage 恢复数据
```

## 14. 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| 网络错误 | 显示"网络错误，请稍后重试"，保留用户输入 |
| 未登录 (401) | 跳转登录页，携带 callbackUrl |
| 积分不足 (402) | 弹窗确认 → 跳转积分充值页 |
| 参数错误 (400) | 显示具体错误信息 |
| 资源不存在 (404) | 显示"资源不存在" |
| 服务器错误 (500) | 显示"服务器错误，请稍后重试" |
